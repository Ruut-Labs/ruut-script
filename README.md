# Ruut Script — релізи

Панель для After Effects (субтитри з тексту, плашка коуча, твіттер-рамка).
Тут лише установка й оновлення; бінарники — у Releases.

- Windows: `RuutScript-Setup-<версія>.exe` роздається приватно (у ньому ключ і все розшифроване), у публічному релізі його немає.
- macOS: один рядок установки (`tools/release/install.sh`); рядок із ключем роздається приватно.
- Наші компоненти (`panel`, `cep`, `library`) у релізах зашифровані; Python, ffmpeg і моделі — загальнодоступні.
- Оновлення: кнопка «Стан і оновлення» в самій панелі; качає лише змінені компоненти за `latest.json`.
- mac-компоненти збирає workflow `mac-components` (запуск вручну з версією після створення релізу).
- `mac-install-test` ставить усе на справжніх маках (Apple Silicon + Intel) тим самим рядком і проганяє субтитри.
